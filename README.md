# Plataforma Web para la Gestión de Cine

Plataforma web multiempresa que centraliza la gestión de un cine y la venta de entradas y snacks en un solo sistema. Los clientes consultan la cartelera, eligen función y asientos, pagan y reciben su comprobante; los administradores mantienen actualizados las películas, salas, funciones, snacks, usuarios, ventas y reportes de su empresa.

> Proyecto académico — Universidad Fidélitas.


## Descripción del problema

La gestión de un cine implica controlar películas, eventos, salas, asientos y venta de entradas. Además, los clientes necesitan realizar de forma integrada la selección de funciones, la selección de asientos, el pago y la compra de snacks.

La falta de un sistema centralizado dificulta el control de la disponibilidad de salas y asientos, así como el registro de las compras y los pagos realizados. Este proyecto propone un sistema que centraliza estos procesos y permite gestionar de forma organizada la venta de entradas y de productos del concesionario.


## Justificación

El sistema permite centralizar los principales procesos de gestión y venta de entradas de un cine. Los clientes pueden consultar la cartelera, seleccionar una función y sus asientos, pagar y agregar snacks a la misma compra. Los administradores pueden mantener actualizada la información y controlar la disponibilidad de asientos, además de llevar un registro de ventas, pagos y comprobantes.

El enfoque **multiempresa** permite adaptar el sistema a distintas empresas del sector cinematográfico dentro de una misma solución tecnológica, manteniendo los datos de cada una de forma independiente.

## Flujo de trabajo en equipo

- Rama principal: `main`.
- Cada integrante trabaja en su propia rama: `feature/nombre-funcionalidad`.
- Los cambios se integran a `main` mediante **Pull Request** revisado por al menos un compañero.
- Mensajes de commit claros y en español, por ejemplo: `Agrega pantalla de cartelera (HU-01)`.
